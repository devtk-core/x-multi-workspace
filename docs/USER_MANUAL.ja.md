# Xnarabi 操作マニュアル

Xnarabi（エックスナラビ）は、複数のXアカウントをひとつのウィンドウに並べて使うための無料Windowsアプリです。最大10個の「管理枠」を作り、枠ごとにX公式サイトを開きます。**XおよびX Corp.の公式製品ではありません。**

このページは一般ユーザー向けです。開発・ビルドの情報は[技術情報](TECHNICAL.ja.md)をご覧ください。

## ダウンロードとインストール

対応環境は**Windows 11 x64**です。Xの閲覧やログインにはインターネット接続が必要です。

1. [Xnarabiの配布ページ（GitHub Releases）](https://github.com/devtk-core/xnarabi/releases/latest)を開きます。
2. 「Assets」から使いたい形式の `.exe` を選びます。Xnarabi版は `Xnarabi-Setup-バージョン-x64.exe`（インストーラー）と `Xnarabi-Portable-バージョン-x64.exe`（ポータブル）です。旧版v1.1.4のファイル名には旧名「X Multi Workspace」が使われています。
3. インストーラー版はexeを開き、画面の案内に沿ってインストールします。ポータブル版はexeを好きな場所に置いて起動します。

配布exeは現時点でコード署名されていません。Windowsが「不明な発行元」やSmartScreenの警告を表示する場合があります。実行する場合は、ダウンロード元が上記の配布ページであることを確認してください。配布ページの `SHA256SUMS.txt` はダウンロードしたファイルが配布物と一致するか確認するためのものですが、それだけで安全性を保証するものではありません。

> **スクリーンショット撮影指示：** 配布ページで「Assets」を展開し、インストーラー版とポータブル版が見える状態を撮影。掲載時点の最新版に合わせ、旧名・新名の違いがある場合は本文も更新する。個人情報は写さない。

## はじめて使うとき

1. Xnarabiを起動し、「管理枠を追加」または左側の **＋** を押します。
2. **表示名**を入力します。必要ならXユーザーID（先頭の `@` を除く）、識別色、ブラウザのズーム倍率も設定します。XユーザーIDは省略できます。
3. 「保存」を押します。新しい管理枠にX公式サイトが表示されたら、**Xの画面上で手動ログイン**します。Xnarabiにパスワードを入力する専用画面はありません。
4. 別のXアカウントも使う場合は、もう一度管理枠を追加し、その枠のX画面でログインします。管理枠ごとにCookieなどの保存領域が分かれています。

X側のログインが有効なら、アプリを閉じて再起動してもログイン状態を利用できます。X側でログアウトやセッション失効が起きた場合は、再ログインが必要です。

> **スクリーンショット撮影指示：** 管理枠の追加画面で表示名、XユーザーID、色、ズームの項目を撮影。実在アカウントのIDは使わず、架空の入力例にする。

## 画面の見方と基本操作

左側の**サイドバー**に管理枠が並びます。名前、XユーザーID、識別色、「表示中」「待機中」「休止中」の状態を確認できます。管理枠をクリックするとその枠を選択します。左上の矢印でサイドバーを折りたためます。

画面上部で **1画面・2分割・4分割・6分割・10分割・タブ** を選べます。分割表示では選択中の管理枠を含むまとまりが表示されます。たとえば6分割で7番目を選ぶと、7番目以降のまとまりへ切り替わります。枠を初めて表示するときにX画面を読み込みます。

各X画面の上部には、次の操作があります。マウスを載せるとボタン名が表示されます。

| 操作 | 内容 |
| --- | --- |
| 戻る・進む | その枠で見たページを移動します。 |
| ホーム・通知 | その枠のX画面で該当ページを開きます。 |
| プロフィール | 管理枠にXユーザーIDを設定していれば、そのIDのプロフィールを開きます。未設定ならXのプロフィール設定ページを開きます。 |
| 投稿 | Xの投稿画面を開きます。送信はX画面で手動で行います。 |
| 再読み込み | その枠のX画面を読み直します。 |
| 拡大表示 | その枠だけを一時的に広く表示します。「分割に戻る」または `Esc` で戻せます。 |
| ⋯ | 管理枠の設定を開きます。 |

画像・動画の添付、文章のコピーと貼り付け、投稿は、各枠のX公式画面で操作します。X側の画面や機能は変更されることがあります。

サイドバーの管理枠は**ドラッグして並べ替え**られます。画面を並べているときは、各画面の上部の黒いバーを別の画面のバーへドラッグすると**表示位置を交換**できます。どちらも管理枠の順序に反映されます。

| キー | 操作 |
| --- | --- |
| `Ctrl+1` ～ `Ctrl+9` | サイドバー順の1～9番目を選択 |
| `Ctrl+0` | 10番目を選択 |
| `Ctrl+R` | 選択中の枠を再読み込み |
| `Ctrl+Shift+P` | 選択中の枠の投稿画面を開く |
| `Esc` | 拡大表示を終了 |

右上の **EN / 日本語** ボタンでXnarabiの表示言語を切り替えられます。X公式画面内の言語はX側の設定に従います。

> **スクリーンショット撮影指示：** 実際のアプリで2分割または4分割を選び、サイドバー、上部のレイアウト切替、各枠の操作バーが見える状態を撮影。投稿・DM・通知などの個人情報を隠す。架空データを合成する場合は「画面イメージ」と明記する。

## 管理枠の追加・変更・削除

- **追加：** サイドバーの **＋** を押します。登録できる管理枠は最大10個です。
- **変更：** 対象画面上部の **⋯** を押し、表示名、XユーザーID、色、ズームを変更して「保存」を押します。ズームは50～200%です。設定画面の「前へ」「後ろへ」でも順序を変えられます。
- **休止：** 設定画面の「休止」を押して確認します。ブラウザ画面を閉じてメモリ使用量を減らします。**編集中の投稿やフォーム入力は失われる場合があります。** 送信・保存してから休止してください。休止中の枠で「復帰する」を押すとX画面を読み直します。ログイン用の保存領域は保持されますが、X側でセッションが失効していれば再ログインが必要です。
- **削除：** 設定画面の「削除」を押すと、管理枠を削除するか確認され、続いてCookieなどのセッションデータも削除するか確認されます。**2回目の確認で「キャンセル」を選ぶと、管理枠だけを削除してデータは残します。**「OK」を選ぶと、その管理枠のCookieやローカルストレージなども消去します。削除した管理枠をアプリから元に戻す機能はありません。データを残しても、新しく作る管理枠には自動で引き継がれません。

一度開いた画面は、別のレイアウトや管理枠に切り替えても閲覧中のページを保つため、メモリ使用量がすぐには下がらない場合があります。参考として、8画面表示時にアプリ全体で約1.4GBを使用した例があります。1画面あたり約100～200MBは大まかな目安で、画像・動画などにより変わります。メモリを減らしたい場合は、下書きがないことを確認してから休止してください。

> **スクリーンショット撮影指示：** 管理枠の設定画面で「前へ」「後ろへ」「休止」「削除」が見える状態と、休止中の画面で「復帰する」が見える状態を撮影。削除確認は架空の管理枠で撮影し、実用中の枠を削除しない。

## 更新方法

Xnarabiは**自動更新しません**。画面上部の「更新を確認」を押すと、GitHubの公開リリース情報を取得します。新しい版が見つかったら「GitHub Releasesを開く」から配布ページへ進み、exeを自分でダウンロードします。確認できない場合も、配布ページを開いて確認できます。

- **インストーラー版：** アプリを閉じ、新しいインストーラーを実行して旧版の上にインストールします。旧名「X Multi Workspace」からXnarabiへの更新も、同じアプリ識別子とデータ保存先を使います。
- **ポータブル版：** アプリを閉じ、新しいポータブル版exeをダウンロードして起動します。古いexeは不要になったら削除できます。管理枠とログイン情報はexeと別のWindowsユーザーデータ領域にあります。

**旧版v1.1.4をお使いの方へ：** リポジトリ名の変更により、旧版のアプリ内「更新を確認」は失敗します。[配布ページ](https://github.com/devtk-core/xnarabi/releases)をブラウザで直接開き、手動で更新してください。旧URLのReleasesページからも新URLへ転送されることを確認しています。

> **スクリーンショット撮影指示：** 新版が公開された後、「更新を確認」から新バージョン案内が表示された画面を撮影。公開前に案内が出ると断定した画像を作らない。バージョン番号とダウンロード先が一致していることを確認する。

## アンインストール

- **インストーラー版：** Xnarabiを閉じ、Windowsの「設定」→「アプリ」→「インストールされているアプリ」からXnarabiを探してアンインストールします。旧版からの移行状況によっては表示名が旧名の場合があります。
- **ポータブル版：** Xnarabiを閉じ、ダウンロードしたポータブル版exeを削除します。

アプリ本体を削除しても、管理枠の設定やXのログイン用データはWindowsユーザー領域に残る場合があります。**完全に消したい場合のみ**、Xnarabiを終了してから、エクスプローラーのアドレス欄に `%APPDATA%\x-multi-workspace` を入力し、そのフォルダーを削除してください。**全管理枠の設定と保存されたログイン状態が消え、元に戻せません。** 新名称のアプリでも互換性のためこの旧名の保存先を使います。

## セキュリティと制約

- Xnarabiは各枠にX公式サイトを表示します。X API、独自サーバー、自動投稿機能は使いません。パスワードや認証トークンをアプリ独自に取得・保存する機能もありません。ログイン操作はX画面で行ってください。
- 管理枠ごとにブラウザの保存領域を分けています。同じPCのWindowsユーザー領域にCookieなどが保存されるため、共有PCではWindowsアカウントの管理にも注意してください。
- X以外のリンクは通常のブラウザで開きます。X画面で開くポップアップは同じ管理枠内で扱います。外部認証を使うログインやポップアップに依存するXの機能は動作しない場合があります。
- カメラ・マイク・画面共有などの権限はアプリ側で許可しません。XのSpacesなど一部機能に影響する可能性があります。画像・動画のファイル添付はX画面から手動で行います。
- Xの利用制限、認証要求、CAPTCHAを回避しません。Xの仕様変更によって、一部の操作ボタンが使えなくなる可能性があります。
- 画面を多く並べるほどメモリを使います。小さい画面で10分割にするとXがモバイル向け表示になったり、操作しづらくなったりします。

## よくある質問

**Q. Xアカウントは何個まで登録できますか？**

A. 管理枠は最大10個です。各枠でX公式画面からログインします。

**Q. アプリを再起動するとログアウトしますか？**

A. X側のセッションが有効なら、保存されたCookieなどを使ってログイン状態を保てます。X側でログインが無効になった場合は再ログインしてください。

**Q. ポータブル版なら設定もexeと一緒に持ち運べますか？**

A. 現行のポータブル版でも設定とログイン用データは、そのPCのWindowsユーザー領域に保存されます。exeだけを別のPCへコピーしてもログイン状態は移りません。

**Q. プロフィールボタンで違うページが開きます。**

A. 管理枠の設定でXユーザーIDを確認してください。未設定の場合はXのプロフィール設定ページを開きます。ログインしているXアカウントと設定したIDが異なる場合、そのIDのプロフィールへ移動します。

**Q. 休止とアプリ終了は何が違いますか？**

A. 休止は指定した枠のブラウザ画面を閉じ、復帰時に読み直します。Cookieなどの保存領域は残ります。編集中の投稿は失われる場合があります。

## 困ったときは

| 症状 | 確認すること |
| --- | --- |
| X画面が表示されない | 接続を確認し、対象枠の「再読み込み」を試してください。休止中なら「復帰する」を押してください。X側の障害や認証画面も確認してください。 |
| ログイン状態が戻らない | 同じWindowsユーザーで起動しているか確認してください。X側のセッション失効、ログアウト、管理枠削除時のセッションデータ消去も考えられます。 |
| アプリ内の更新確認が失敗する | 接続を確認してください。旧版v1.1.4ではリポジトリ名変更後に失敗するため、[配布ページ](https://github.com/devtk-core/xnarabi/releases)をブラウザで開いてください。 |
| メモリ使用量が多い | 下書きを保存したうえで、使っていない枠を休止してください。レイアウトを小さくするだけでは読み込み済み画面のメモリはすぐには解放されません。 |
| 外部認証や通話が動かない | 外部認証用ポップアップや、カメラ・マイク・画面共有の権限が必要な機能は利用できない場合があります。必要に応じて通常のブラウザでXを開いてください。 |
| Windowsの警告が表示される | 配布exeは未署名です。実行前にファイル名、ダウンロード元、配布ページのチェックサムを確認してください。ファイアウォールの受信許可は通常のX閲覧・投稿には不要です。 |

解決しない場合は、利用中の版、Windowsの版、再現手順、表示されたエラーを控え、[GitHub Issues](https://github.com/devtk-core/xnarabi/issues)で報告できます。**パスワード、認証コード、Cookie、投稿の下書きなどは添付しないでください。**
