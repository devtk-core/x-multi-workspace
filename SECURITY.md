# Security policy

If you find a security issue, please report it privately. Do not include account credentials, session data, or exploit details in a public issue.

Use the repository's **Security → Report a vulnerability** page if it is available to you. If that option is unavailable, contact the repository owner privately through their GitHub profile to arrange a reporting channel before sharing details.

Include the affected app version, a brief description, and steps to reproduce with dummy data. We will investigate and coordinate a fix before public disclosure.

Only the latest release is intended to receive security fixes. This project is not affiliated with X.
